# Посмотри в окно

Учебный сайт: поиск видео по городу и времени суток, переключение основного видео, прокручиваемый список и кнопка «Показать еще».

## Запуск

В папке проекта выполните:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Для загрузки видео нужен доступ к интернету: приложение использует API https://v-content.ffapi.ru.

Для подготовки отдельной статической сборки выполните `node build.mjs`. Она появится в `dist/`.

## Устройство проекта

- `index.html` — разметка и шаблоны карточек, прелоадера и ошибки.
- `styles/style.css` — сетка, типографика, состояния интерактивных элементов и чекбоксов.
- `styles/preloader.css`, `styles/error.css` — оформление состояний загрузки и ошибки из стартового проекта.
- `scripts/script.js` — исходная логика поиска и переключения видео.
- `fonts/` — локальные Oswald и Fira Sans Condensed в форматах WOFF2 и WOFF.

Минимальная ширина страницы — 1200px, как в стартовом проекте. Основная композиция занимает 1140px: плеер 711px, промежуток 30px, правая колонка 399px. Основной лейаут выполнен на flex; абсолютное позиционирование в `style.css` используется только для `.visually-hidden`.

Адрес API обновлён на `https://v-content.ffapi.ru`, используемый актуальным официальным шаблоном: прежний `v-content.practicum-team.ru` не отвечал при проверке. Остальная логика стартового скрипта сохранена.

## Проверка

В Chromium с реальным API проверены: начальная загрузка, поиск по городу и времени суток, догрузка карточек, переключение видео, пустой результат, восстановление после него, ошибка сети, выбор чекбоксов и навигация Tab. На ширинах 1200, 1440 и 1920px горизонтальной прокрутки нет.

Точное пиксельное сравнение с Figma не выполнено: сервис не предоставил содержимое макета в этой среде.

Firefox не удалось запустить в этой среде из-за ошибки графического движка; проверка в нём остаётся отдельным шагом.
